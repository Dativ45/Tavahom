# اتاق وضعیت | Status Room

موتور اولیه خبرخوان و انتشار خودکار کانال تلگرام.

## امکانات
- اجرای زمان‌بندی‌شده سه بار در روز (UTC).
- خواندن چند خوراک خبری.
- جلوگیری از انتشار دوباره یک لینک/خبر.
- انتشار تیتر، خلاصه در صورت فعال‌بودن API، نام منبع و لینک.
- اجرای آزمایشی دستی از بخش Actions.

## نصب امن
از لینک تنظیمات Secrets مخزن استفاده کنید: https://github.com/Dativ45/Tavahom/settings/secrets/actions سپس New repository secret را بزنید و این نام‌ها را دقیقاً ثبت کنید:

- `TELEGRAM_BOT_TOKEN` — توکن BotFather
- `TELEGRAM_CHAT_ID` — آیدی کانال، مانند `@StatusRoomGlobal`
- `OPENAI_API_KEY` — اختیاری؛ برای خلاصه‌سازی با API (هزینه جدا از اشتراک ChatGPT)

ربات باید در کانال مدیر و دارای مجوز ارسال پیام باشد. توکن را در کد یا چت قرار ندهید.

## اجرا
از Actions، گردش‌کار «Status Room publisher» را باز کنید و Run workflow را بزنید.

## محدودیت‌های نسخه اول
این نسخه یک خبر از خوراک‌ها را در هر اجرا منتشر می‌کند. هنوز راستی‌آزمایی مستقل دو منبع، پایش لحظه‌ای خبر فوری، داشبورد مدیریت و تأیید انسانی قبل از انتشار را ندارد. برای خبرهای حساس، انتشار خودکار بدون بررسی تحریریه مناسب نیست.

زمان‌بندی اجراها: ۰۵:۰۰، ۱۱:۰۰ و ۱۷:۰۰ UTC؛ معادل ۰۸:۳۰، ۱۴:۳۰ و ۲۰:۳۰ به وقت ایران. زمان‌بندی GitHub Actions ممکن است چند دقیقه تأخیر داشته باشد.
